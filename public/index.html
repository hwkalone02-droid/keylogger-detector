About this demo

This mock auth UI is lightweight and suitable for pairing with your static JS analyzer and runtime mutation-observer detector. For the hackathon, focus on:

  • Static scan of loaded JS bundles to find keystroke-listening patterns.
  • Runtime detector: observe DOM for injected listeners / unusual event handlers.
  • Display scan results in a separate scanner UI (we can add that next).
Integration point: replace the mockAuth functions with real API calls. Expose window.KeyWatch.reportSuspicious() to send runtime detections to the scanner view.
Security reminder: This demo stores credentials in localStorage for convenience only. Do not use as-is in production.
